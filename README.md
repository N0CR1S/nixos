# nixos

These are my nixos configuration files.

It is a hyprland caelestia rice.

Nixos is a linux distribution that is so called reproducible and declarative.

With this files everyone can reproduce my setup.

### Notes:

Caelestia isnt fully supported on nixos.

Most important things work but not all the settings.

You will not notice that during daly use.

The file hardware-configuration.nix has to be deleted and replaced on every computer.

How to do this is writen in the nixos wiki.

You may want to change usr and passwd.

For the wallpaper:

You should place all your wallpapers in "~/Pictures/Wallpapers".

You should name one wallpaper "wallpaper.jpg".

This will be shown for a short time on each startup when caelestia isnt loaded.

For all other wallpapers, place them in the same folder and select them via the caelestia settings.
